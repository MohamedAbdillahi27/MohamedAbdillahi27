## 🚀 Featured Project

### 🔎 AyahFind — Intelligent Qur'an Search

🌐 **Website:** [ayahfind.com](https://ayahfind.com)

AyahFind is a Qur'an search platform I'm developing to make finding verses easier, even when users don't remember the exact wording.

**Key Features:**
- Semantic search across 6,236 Qur'anic verses
- Arabic, English and transliteration-based search
- Arabic voice search
- Fuzzy text matching and unified result ranking
- Interactive Qur'an reader with navigation and recitation
- Full-stack deployment

**Tech Stack:**
- **Frontend:** Next.js, React, JavaScript
- **Backend:** Python, FastAPI
- **Search & AI:** FAISS, semantic search, NLP
- **Infrastructure:** Docker, Vercel, Render

Through AyahFind, I'm developing practical experience in information retrieval, backend engineering, AI-powered applications and deployment.
